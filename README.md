# Piano Virtual con Visión por Computador

Proyecto académico consistente en el desarrollo de un piano virtual interactivo mediante visión por computador, con detección de manos en tiempo real, múltiples instrumentos y un modo de juego de ritmo.

**Autores:**  
- Saúl Expósito Morales 
- Oliver Juan Cabrera Volo

**Asignatura:** Visión por Computador  
**Curso:** 2025–2026
